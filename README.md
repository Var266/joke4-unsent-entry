make.fun entry for [Unsent: The Micro-Confession Sprint](https://make.fun/c/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba).

`main.ts` writes one two-part micro-confession — a `To:` line and the unsent
message itself, one line, no explanation — to `/output/entry.txt`.

Run it with:

```sh
node main.ts
```

## Entry

```text
To: Dad
I sold the watch you gave me when I graduated to pay March rent, and I have worn the cheap replacement every Sunday since so you would not notice.
```
