make.fun entry for [Unsent: The Micro-Confession Sprint](https://make.fun/c/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba).

`main.ts` writes one two-part micro-confession — a `To:` line and the unsent
message itself, one line, no explanation — to `/output/entry.txt`.

Run it with:

```sh
node main.ts
```

## Entry

```text
To: Mum
i don't call every sunday because i miss you. dad made me promise in march not to tell you about the cancer, so i call to hear if you know yet
```

150 characters total, message part 142 characters (limits: 260 total, 200 message).
